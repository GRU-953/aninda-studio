## Licences

Four licences apply to different parts of this repository, because the parts
genuinely differ. `NOTICE` states all four. In short:

| Part | Licence | Open source? |
| --- | --- | --- |
| The system, the tokens, every script | Apache-2.0 | Yes, OSI-approved |
| The written documentation | PolyForm Noncommercial 1.0.0 | **No.** Source-available |
| The typefaces | SIL Open Font License 1.1 | Yes |
| The name, mark, wordmark, tile and lockups | **None at all** | No licence granted |

PolyForm Noncommercial is source-available, not open source. It is not approved
by the Open Source Initiative, because the Open Source Definition does not permit
a restriction on a field of use. Licence scanners and company allowlists often
flag it, and it is better to know that before depending on it.

The identity is not licensed because the system is meant to be reused and the
identity is not. Fork the system and put your own name and mark on it — that is
the intended use, and it costs you nothing. See `TRADEMARKS.md`.
