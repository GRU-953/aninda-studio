Bangla review sheet

Every Bangla string the Aninda Studio system currently intends to ship, at the exact size and in the exact face it will ship in — Noto Serif Bengali, beside Literata.

The automated checks have already proved that none of this is broken: the মাত্রা is continuous across all 866 pixel columns measured, all sixteen tested conjuncts shape correctly, no glyph is missing. What no check can prove is whether it is good.

What to look for, in order of how much it matters
  • Does it read as Bangla, or as English in Bangla script? The rule this system sets itself is that Bangla is written as Bangla — same meaning, different sentences — never translated word by word. Row 18 sets the register for everything else, so start there.
  • Is the word the one a Bangladeshi reader would actually use? Several rows below offer a formal Bangla word and an English loanword, because I genuinely do not know which is right. Pick.
  • Is the register consistent? A studio run by one person should not sound like a government form.
  • Do any conjuncts look wrong? Row 23 is the stress test. If a form there looks broken, that is the font or the shaping, not the wording — tell me and I will fix it at that level.
  • Row 24 is at the 12px floor. If the মাত্রা has greyed out on your screen, the floor is too low and I will raise it.

Why this page has buttons instead of printed boxes. The first version of this sheet was a PDF with boxes to tick. It came back with nothing in it — the annotations were made in a viewer that never wrote them into the file, and there was no way to tell that had happened until the boxes were read back and found empty. Marks made here are read straight out of the page, so they cannot go missing the same way.
