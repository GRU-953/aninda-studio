# The marks and the name

**Short version: take the system, leave the identity.**

Everything that makes this design system work — the tokens, the stylesheets, the
components, the scripts — is Apache-2.0, and you are welcome to it, including for
commercial work. What is not on offer is the identity sitting on top of it.

## What is not licensed

None of the following is licensed to anyone, by any file in this repository:

- The name **Aninda Studio**
- The Bangla name **অনিন্দ্য**
- The mark — the lowercase `a` built from a circle and an overrunning stem
- The wordmark, in either script
- The tile and every icon derived from it
- Any lockup combining the mark with either wordmark

They are not open source. They are not source-available. No permission is granted
to use them, and none is implied by the Apache-2.0 licence covering the code that
happens to draw them.

## Why it is set up this way

A design system is more useful the more people use it. An identity is the opposite:
it only works while it points at one person. If two studios shipped the same mark,
it would have stopped doing its job for either of them.

So the split is deliberate, and it is meant to be generous rather than restrictive.
Fork the system, run the colour engine with your own anchor colours, put your own
name and mark on the result. That is the intended use, it costs you nothing, and
the scripts are written to make it straightforward.

## What you may do without asking

- Use the design system in your own work, commercially or not.
- Say truthfully that your work is built on the Aninda Studio design system.
- Reproduce the mark in commentary, criticism, teaching or reporting about the
  studio — the ordinary uses that do not need anyone's permission.
- Link to the site or the repository, using the name as a plain word.

## What needs a conversation first

- Using the mark, the wordmark or a lockup as an identifier for anything you make.
- Anything that could reasonably suggest the studio built, endorsed or approved
  your work when it did not.
- Modifying the mark and continuing to call it Aninda Studio.

Ask, and you will get a straight answer: **aninda.sh15@gmail.com**

## If you are using the system

You do not need to credit the studio, and there is no badge to display. If you want
to, this is the wording that is accurate:

> Built on the Aninda Studio design system.

That is it. No logo, no link required.
