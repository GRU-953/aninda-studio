There is a second reason this chapter has no Bangla body, beyond the general
one. A chapter that tells you how to write standard Bangla should not be the
place where unreviewed Bangla is introduced. The English section carries the ten
house rules, the punctuation rules and the full list of what is unverified.

## The words the rules turn on

Each of these is quoted from the Bangla Academy's 2012 rules or from *আধুনিক
বাংলা অভিধান*. None of them was written for this book.

{{table: The spellings this book uses, the ones it does not, and the ruling behind each.}}
| Use this | Not this | Why |
|---|---|---|
| এখনো | এখনও | এখনও is only a cross-reference to এখনো in the dictionary |
| আরও | আরো | The dictionary calls আরও the সংগততর — more consistent — spelling |
| কোনো | কোন | কোনো is *any* or *some*; কোন is *which* |
| রং | রঙ | Rule 2.4 names রং; রঙ has no dictionary entry |
| রঙিন, রঙের | — | রঙ appears only when a vowel follows it |
| ছোটো, বড়ো | ছোট, বড় | Rule 2.3; both are dictionary headwords, neither short form has an entry |
| ধরন, রানি, সোনা, ঝরনা | — | Rule 2.7: no ণ in any non-Sanskrit word |
| সফটওয়্যার | সফ্টওয়্যার | Rule 2.10: avoid the hasanta where it is not needed |
| কপি, ফাইল, মেগাবাইট | অনুলিপি, নথি | Rule 2.6: established loanwords are standard Bangla |
| পদ্ধতি | ব্যবস্থা | ব্যবস্থা reads administrative in Bangladeshi usage |

## The chapter title itself

The Bangla title of chapter 14 is **{{bn:gb-10}}**, and it is one of the six
strings the review changed. The draft used ব্যবস্থা, which is correct in the
abstract but lives in official notices — ব্যবস্থা নেওয়া, আইনগত ব্যবস্থা — and imports
exactly the institutional tone that chapter is trying to disown. পদ্ধতি is a
dictionary headword and the ordinary Bangla for a system in technical writing,
as in সংখ্যা পদ্ধতি.
